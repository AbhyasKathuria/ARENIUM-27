# ARENIUM 26 – The Arena of Innovation

A futuristic, animated, and interactive website designed for **AREN IUM 26**, the Annual Inter-College Tech Fest organised by the **School of Information Science, Presidency University**.

This project showcases modern frontend development concepts, immersive UI/UX design, and event-oriented web architecture.

---

## 📌 Event Details

- **Event Name:** ARENIUM 26  
- **Tagline:** The Arena of Innovation  
- **Dates:** 5th & 6th February  
- **Time:** 9:30 AM – 7:00 PM  
- **Venue:** Presidency University  
- **Organised By:** School of Information Science  
- **Participants:** UG Students (Inter-College)  

---

## 🚀 Project Features

### 🎨 UI / UX
- Futuristic dark theme with neon highlights
- Glassmorphism design
- Animated gradient background
- Hover effects and smooth transitions
- Tech-styled typography (Orbitron font)

### ⚡ Interactivity
- Live event countdown timer
- Mouse-based parallax logo effect
- Animated statistics cards
- Netflix-style logo transition on registration success

### 📝 Registration Flow
- Interactive registration form
- Full-screen success animation
- Automatic redirect to homepage after submission

---

## 🛠️ Technologies Used

- **HTML5** – Structure & semantics  
- **CSS3** – Styling, animations, glassmorphism  
- **JavaScript (Vanilla JS)** – Countdown, parallax effects, form handling  

No external libraries or frameworks were used.

## ▶️ How to Run the Project

1. Download and extract the project folder
2. Open `index.html` in any modern web browser
3. Click **Register Now** to access the registration page
4. Fill the form and submit to view the success animation

**No server, internet connection, or dependencies required.**
